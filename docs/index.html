Option 4 is a one-time setup so it never asks for your password again. Read Security first.

How it works

The Query Log's Time column is drawn by a small function inside queries.js. The patch swaps that one function for a friendlier one. Hover any time to see the original.

Stock
2026-05-23 18:42:01
arrow_forward
Patched
Today 6:42:01 PM

Older entries show Yesterday 11:15:32 PM, Apr 16, 9:03:10 AM, or Dec 3 2025, 4:20:00 PM. Only what's displayed changes; sorting, search and export still get the raw timestamp.

  1. The script is fetched from GitHub on the Pi, or uploaded from your PC by the Windows launcher.computerPC → Pi
  2. It runs as administrator with sudo, since Pi-hole's files belong to the system.memoryPi
  3. The script backs up the current stock file to queries.js.orig, writes the patched copy to a temp file, and only then moves it into place. If anything fails, the original isn't touched.memoryPi
warning

Every Pi-hole web update replaces queries.js, which is why the patch needs re-running after updates.

Other ways to run it

Download first, then run: for anyone who prefers to read a script before running it.

curl -fsSL https://raw.githubusercontent.com/Mythodix/pihole-time-format/main/pihole-time-format.sh -o ~/pihole-time-format.sh
chmod +x ~/pihole-time-format.sh
less ~/pihole-time-format.sh              # read it first (q to quit)
sudo bash ~/pihole-time-format.sh apply

Commands for a downloaded copy:

bash ~/pihole-time-format.sh status         # patched? can this version be patched?
sudo bash ~/pihole-time-format.sh apply     # apply the patch
sudo bash ~/pihole-time-format.sh restore   # put Pi-hole's stock file back

Patching from macOS or Linux (the .bat files are Windows-only):

scp pihole-time-format.sh pi@pi.hole:~/
ssh -t pi@pi.hole "chmod +x ~/pihole-time-format.sh && sudo ~/pihole-time-format.sh apply"

Troubleshooting

terminalWindows: "ssh isn't available"expand_more

The OpenSSH Client isn't installed. Add it from Settings › System › Optional features › Add a feature › OpenSSH Client, then run the .bat again.

lanPermission denied, timed out, or "could not resolve hostname"expand_more

Permission denied means a wrong password or username. Timed out or could not resolve means a wrong address, or the Pi is off. On Windows, choose 5 · Change Pi or username to fix the saved details.

passwordWindows still asks for a password after option 4expand_more

If you already had an SSH key with a passphrase, Windows asks for that instead. Delete %USERPROFILE%\.ssh\id_ed25519 and its .pub file, then run option 4 again.

refreshPatched, but the browser shows the old formatexpand_more

The browser is using a cached copy. Press Ctrl + F5 on the Pi-hole tab. If it's still unchanged, run the install line with status instead of apply.

upgrade"Could not find the Time column" or "Patchable: NO"expand_more

A Pi-hole update changed the Query Log's code and the patch needs updating to match. Nothing was changed on your Pi; the script stops before touching the file.

travel_explore"queries.js not found"expand_more

Pi-hole's web files have moved. Find the file, then point the script at it:

sudo find / -path '*scripts/js/queries.js' 2>/dev/null
sudo PIHOLE_QUERIES_JS=/path/to/queries.js ~/pihole-time-format.sh apply
healingThe Query Log looks broken after patchingexpand_more

Run the install line with restore instead of apply, then Ctrl + F5. If the backup is missing, sudo pihole -r (Repair) reinstalls Pi-hole's stock web files.

Security

Only relevant if you choose 4 · Stop asking for my password in the Windows launcher.

  • admin_panel_settings
    Sudo rule. Lets your account run ~/pihole-time-format.sh as root without a password, and nothing else. Your account can edit that file, so on a home Pi where you already have sudo it adds nothing new. Don't use it on a Pi other people log into.
  • vpn_key
    SSH key. Created without a passphrase so patching needs no typing. Anyone who can use your Windows account could use it to log into the Pi.
  • lock
    Passwords. Never stored in any of these files. You type them at the prompts.

Uninstall

Run on the Pi. Lines 2 and 3 are only needed if you used Windows option 4. On Windows, also delete the %APPDATA%\pihole-time-format folder.

curl -fsSL https://raw.githubusercontent.com/Mythodix/pihole-time-format/main/pihole-time-format.sh | sudo bash -s restore  # 1. stock timestamps back
sudo rm /etc/sudoers.d/pihole-timeformat               # 2. remove the sudo rule
sed -i '/pihole-time-format$/d' ~/.ssh/authorized_keys # 3. remove the setup's key
rm -f ~/pihole-time-format.sh                          # 4. delete any downloaded copy
sudo rm -f /var/www/html/admin/scripts/js/queries.js.orig # and the backup

Line 3 only removes keys the setup created. If setup reused a key you already had, leave it unless you want to remove it by hand.
